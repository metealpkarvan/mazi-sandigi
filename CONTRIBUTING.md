# Contributing

Start with a concrete problem or a small improvement. Include your Mac model, CPU architecture, macOS version and reproduction steps for bugs. Use fictional memories and generated test images in public reports; personal stories/photos should remain private.

Build and run the rule runner and native smoke checks documented in README. Changes to persistence must preserve the original file on failures, validate imports before replacement and include a meaningful regression check. Changes to games should keep the UI and test engines shared.

Keep minimum macOS 11 availability and both Intel/arm64 compilation. Native Apple Silicon checks complement cross-compilation. Keep the Turkish interface clear and update the English guide where behavior changes. Record cultural source claims and distinguish inspiration from documented history. Do not add song/photograph assets without clear redistribution rights.

Avoid remote dependencies unless the capability requires them and the changed data boundary is documented. Publish only real changed behavior; do not invent adoption metrics.
